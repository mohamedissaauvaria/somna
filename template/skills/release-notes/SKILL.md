# Release notes (example)

1. Read ~/somna/memory/work/releases.md and follow it.
2. List the merged changes since the last tag (`git log <last-tag>..HEAD --oneline`).
3. Group them as Added, Changed, Fixed. Leave out internal refactors.
4. Write one plain sentence per change, from the user's point of view.
5. Follow ~/somna/memory/me/writing-style.md for wording.
